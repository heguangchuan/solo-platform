服务器管理模块 HTML 原型

覆盖服务器管理入口、列表查询、新增编辑、删除确认、服务器详情、Web 终端、文件管理、上传下载查看、异常提示和安全边界。

原型说明

本文件为静态 HTML 原型，用于说明页面布局、字段、按钮、状态和交互流程；不包含真实后端接口调用。后续编码阶段需结合项目现有前端框架、路由、权限、接口规范和组件库实现。

建议后端根据关联数据判断是否允许删除；如存在关联任务或操作记录，可提示禁止删除或执行逻辑删除。

八、上传、下载、查看文件交互

上传文件

选择目标目录后点击“上传文件”，选择本地文件并提交。

上传前校验：文件大小、文件名、目标路径、同名文件处理策略。
下载文件

文件行点击“下载”，后端检查权限和文件存在性后返回文件。

目录不直接下载；如需目录下载，后续另行设计压缩下载能力。
查看内容

点击“查看”后展示文本内容；过大或二进制文件给出提示。

二进制文件暂不支持在线预览。

十、核心交互流程

服务器新增/编辑流程

进入列表
用户打开服务器管理页面。
填写表单
录入服务器名称、地址、端口、认证信息。
保存校验
校验必填、格式、权限和唯一性。
刷新列表
保存成功提示并刷新服务器列表。

Web 终端流程

选择服务器
从列表或详情点击 Web 终端。
权限校验
判断用户是否有终端访问权限。
建立连接
读取连接配置并连接服务器。
执行命令
展示命令输出和异常提示。

文件管理流程

进入文件管理
从列表或详情点击文件入口。
读取目录
展示当前路径、目录和文件。
文件操作
上传、下载、查看文本文件。
异常处理
展示权限、路径、网络和文件大小提示。
